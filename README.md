# Crypto Tracker

A lightweight and fast web application to track real-time cryptocurrency prices using the **CoinGecko API**.

## 🛠 Tech Stack
- **JavaScript** — Modular architecture using Import/Export.
- **Asynchronous JS** — Handling data with `fetch` and `async/await`.
- **CSS Grid & Flexbox** — Fully responsive layout for all devices.
- **HTML5** — Clean structure.

## 🌟 Key Features
- **Live Data:** Fetches current prices for the top 20 cryptocurrencies.
- **Advanced Error Handling:** Specifically handles **HTTP 429 (Too Many Requests)** errors with user-friendly visual feedback.
- **Responsive Design:** Optimized for desktops, tablets, and smartphones.
